# Atelier

**The programmable coding studio. Code, extend, and run anywhere.**

Atelier is your place to build software with agents. Open a project, settle into
the work, and keep the conversation, code, tools, and context together.

It is not a prescribed workflow. Atelier starts as a focused coding studio and
becomes yours as you use it: add the pages you need, put actions where they are
useful, connect services, and give agents new tools. Extensions are part of the
studio rather than a separate product bolted onto it.

## Work there

Each project has a home. Start a task, leave it, and come back without rebuilding
its context. Keep several pieces of work open, move between them, and steer or
stop an agent while it works.

Atelier stays close to the code. It runs locally, works with the projects already
on your machine, and keeps the controls for the work in one place.

## Make it yours

A studio should fit the person using it. Atelier can be extended while it is
running with plugins that add pages, actions, views, backend services, and tools
for agents.

Build a project dashboard. Add a release action. Connect an internal service.
Turn a repeated workflow into a tool. If something is missing from your studio,
you can make it part of the studio.

## Give agents their own space

Run an agent directly on your machine when that is what you want, or give a chat
its own Docker Sandbox. Sandboxed agents get an isolated place to work while the
project and the rest of Atelier remain on your machine.

Choose the right space for the task without changing how you work.
